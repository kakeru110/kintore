# SIGNAL - 筋トレ記録アプリ

種目・重量・回数・セット数を記録し、進捗をグラフで確認できるシンプルな筋トレ記録アプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）です。

## 使い方

`index.html` をブラウザで開くだけで利用できます。ローカルで確認する場合は、例えば以下のように簡易サーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### GitHub Pages で公開して使う（複数端末で同期する場合はこちら）

1. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
2. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
3. 公開されたページを開き、「GitHub同期の設定」からトークンを登録すると端末間で記録が同期されます（下記参照）

## 機能

- 日付・種目・重量・回数・セット数・メモを記録
- 種目名はこれまでの入力から入力補完
- `YYMMDD場所` + `種目名 重量-回数, 重量-回数, ...` 形式のテキストをまとめて貼り付けるインポート機能（連続する同じ重量・回数は自動でセット数にまとめ、認識できない行は警告として表示）
- 記録一覧（日付ごとにグループ化、削除可能、種目で絞り込み可能）
- 概要（総記録数・種目数・直近7日間の実施日数）
- 種目ごとの重量推移グラフ（ホバーで日付と重量を表示）
- ライト/ダークモード対応
- GitHub 経由の端末間同期（任意）

## データについて

記録は常にブラウザの `localStorage` に保存されます。それに加えて、GitHub の個人アクセストークンを登録すると、
このリポジトリの `data/records.json` を介して他の端末と同期できます。

同期を使う場合:

1. [トークン発行ページ](https://github.com/settings/personal-access-tokens/new) で、対象リポジトリを `kakeru110/kintore` のみに限定し、Permissions → Contents を Read and write にしてトークンを発行
2. アプリの「GitHub同期の設定」にトークンを貼り付けて保存（同期したい端末それぞれで1回ずつ）
3. 追加・削除・インポートのたびに `data/records.json` へ自動で反映され、他の端末を開いたときに最新の記録が読み込まれます

同時に別の端末から更新した場合はバージョンを照合し、安全に統合されます（記録が失われることはありません）。

トークンを登録しない場合は、これまで通りその端末の `localStorage` にのみ記録が保存されます。

**注意:** claude.ai の Artifact プレビュー（`claude.ai/code/artifact/...`）はセキュリティ上の制約で外部通信ができないため、
GitHub同期は動作しません。同期を使う場合は GitHub Pages で公開したページを開いてください。
